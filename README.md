# Sales Performance Dashboard

Excel sales analysis dashboard built as my capstone project for the TS Academy Data Analytics programme.

## What I did
- Analysed 2,098 sales transactions (January–May 2025) across 10 products, 4 cities, and 6 sales reps
- Calculated revenue, COGS, and profit with Excel formulas
- Built PivotTables, charts, and slicers for an interactive dashboard

## Key findings
- Total revenue: ₦2.33 billion, with profit of ₦465.7 million
- Laptop A13 was the top profit driver (₦105.3 million)
- Peter was the highest-revenue sales rep (₦434.8 million)

## Tools
Microsoft Excel (formulas, PivotTables, charts, slicers)
